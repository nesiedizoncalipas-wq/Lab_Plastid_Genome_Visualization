# Plastid Genome Visualization

## Project Overview

This project focuses on visualizing the chloroplast genome of *Glycine soja* isolate HAAS216 using OGDRAW. The genome map shows the organization of the plastid genome, including its genes, major regions, and GC content.

## Genome Information

- **Scientific Name:** *Glycine soja*
- **Isolate:** HAAS216
- **GenBank Accession:** PX591265.1
- **Genome Length:** 152,222 bp
- **Genome Type:** Circular chloroplast genome
- **Visualization Tool:** OGDRAW

## Project Objectives

- Visualize the structure of the chloroplast genome.
- Identify the LSC, SSC, IRa, and IRb regions.
- Observe gene locations and transcription directions.
- Examine the GC content across the genome.
- Understand how a graphical genome map helps in genome analysis.

## Repository Contents

- `data/` — Contains the GenBank file used for the genome visualization.
- `figures/` — Contains the generated chloroplast genome map.
- `answers/` — Contains the answers to the laboratory questions.
- `README.md` — Provides an overview of the project.

## Methodology

1. Obtained the chloroplast genome sequence of *Glycine soja* from GenBank.
2. Used the GenBank file as input for OGDRAW.
3. Generated a circular chloroplast genome map.
4. Examined the major genome regions, gene annotations, and GC content.
5. Prepared answers to the laboratory questions based on the genome visualization.

## Results

The OGDRAW visualization presents the circular chloroplast genome of *Glycine soja*. It shows the arrangement of genes and the major genome regions, including the LSC, SSC, IRa, and IRb. The map also displays GC content information, making the genome structure easier to understand.

## Conclusion

This activity helped me understand the organization of a chloroplast genome and how to visualize its structure using OGDRAW. The graphical map makes it easier to identify genome regions, gene locations, and GC content compared with examining the raw DNA sequence alone.
